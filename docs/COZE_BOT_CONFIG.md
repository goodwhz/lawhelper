# Coze 智能体配置问题说明

## 问题描述

**现象**:
- 前端输入数字后,AI 立即返回评分结果
- Coze 后台查看对话历史,显示的是正常的多轮提问流程
- 用户输入的数字应该触发下一个问题,而不是直接给出评分

## 根本原因

这是一个 **Coze 智能体配置问题**,不是前端代码的问题。

### 可能的原因

#### 1. 智能体设置了自动完成检测

Coze 智能体可能配置了在接收到某些输入时自动完成任务:

```
输入: "100000"
智能体判断: "这是薪资数据,应该已经收集完所有信息"
智能体行为: 直接输出评分结果
期望行为: 继续提问工作时长等信息
```

#### 2. Prompt 配置过于宽松

智能体的系统提示词可能包含:

```
"当用户输入数字时,可以认为信息收集完成"
```

这样的配置会导致智能体在第一次输入数字时就跳过后续问题。

#### 3. 工作流配置错误

Coze 的工作流可能配置了条件跳过逻辑:

```
条件: 当接收到年薪数据
动作: 跳到评分环节
期望: 继续询问其他维度
```

#### 4. 缺少多轮对话逻辑

智能体可能没有配置明确的多轮对话流程,导致它自由判断何时完成。

## 解决方案

### 方案 1: 修改 Coze 智能体配置 (推荐)

#### 修改系统提示词 (Prompt)

在 Coze 平台编辑智能体,修改系统提示词:

```markdown
# 系统提示词

你是一个专业的职场处境测评助手。请按照以下步骤进行测评:

## 测评流程

1. **信息收集阶段** (必须完成所有步骤)
   - 步骤 1: 询问年薪
   - 步骤 2: 询问工作时长
   - 步骤 3: 询问加班频率
   - 步骤 4: 询问职位级别
   - 步骤 5: 询问行业类型
   - 步骤 6: 询问公司规模
   - 步骤 7: 询问工作压力感受
   - 步骤 8: 询问成长机会
   - 步骤 9: 询问团队氛围
   - 步骤 10: 询问公司福利

2. **重要规则**
   - ✅ 必须完成所有 10 个步骤,不能跳过
   - ✅ 每个步骤只回答一个问题
   - ✅ 用户输入数字后,继续问下一个问题
   - ✅ 只有在收集到足够信息后才给出评分
   - ✅ 不要因为用户输入数字就认为测评完成

3. **评分阶段**
   - 只有收集完所有维度信息后才进行评分
   - 输出详细的评分报告
   - 提供改善建议

## 禁止行为

❌ 不要在用户第一次输入数字后就给出评分
❌ 不要跳过任何一个提问步骤
❌ 不要自行判断测评完成时机
❌ 不要在没有收集完整信息前输出评分

## 输出格式

在完成所有问题后,按照以下格式输出评分:

```json
{
  "total_score": 85,
  "dimensions": {
    "薪资回报": {
      "score": 80,
      "factors": ["年薪低于行业平均水平", "涨幅有限"]
    },
    "工作强度": {
      "score": 70,
      "factors": ["工作时长较长", "加班频率较高"]
    }
    ...
  },
  "summary": "综合来看,您的职场处境...",
  "suggestions": [
    "建议 1",
    "建议 2",
    ...
  ]
}
```
```

#### 修改工作流 (Workflow)

在 Coze 平台配置工作流,确保严格的提问顺序:

```yaml
workflow:
  start:
    - action: ask_salary
      next: ask_work_hours

  ask_work_hours:
    - action: ask_work_hours
      next: ask_overtime

  ask_overtime:
    - action: ask_overtime
      next: ask_job_level

  # ... 其他步骤

  # 只在所有步骤完成后才评分
  evaluate:
    - action: calculate_score
      next: output_result

  # 不能在中间步骤直接跳到 evaluate
  # 不能根据用户输入判断跳过步骤
```

### 方案 2: 添加确认步骤

在智能体中加入确认环节:

```markdown
在收集完所有信息后,询问:

"我已经收集了以下信息:
- 年薪: [用户输入]
- 工作时长: [用户输入]
- 加班频率: [用户输入]
...

请确认这些信息是否正确?如果需要修改,请告诉我;如果确认无误,我将开始评分。"
```

### 方案 3: 明确的步骤标记

让智能体明确告诉用户当前是第几步:

```markdown
[步骤 1/10] 请输入您的年薪(例如: 100000):
```

这样用户知道还有多少步骤,智能体也更难跳过。

### 方案 4: 添加进度指示

在每个回答中显示进度:

```markdown
当前进度: ██████░░░░░░ 40% (4/10)
```

### 方案 5: 前端强制多轮 (临时方案)

如果无法修改 Coze 配置,可以在前端强制多轮对话:

在 `app/api/spark-evaluator/chat/route.ts` 中添加:

```typescript
// 检测是否是第一次对话
const isFirstMessage = messages.length === 0

// 如果用户输入的是纯数字,说明是回答第一个问题
const isNumericInput = /^\d+$/.test(message.trim())

// 如果是第一个问题的回答,强制重新提问
if (isFirstMessage && isNumericInput) {
  const followUpQuestion = "好的,年薪已记录。接下来请告诉我您每周工作多少小时?"
  return NextResponse.json({
    success: true,
    data: { message: followUpQuestion }
  })
}
```

**注意**: 这是临时方案,建议优先修复 Coze 智能体配置。
